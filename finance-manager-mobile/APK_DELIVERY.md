## 🔧 **Troubleshooting**

### **APK Won't Install**
- Check Android version (need 8.0+)
- Enable "Unknown Sources" in settings
- Download correct architecture (arm64 for most phones)

### **App Crashes**
- Uninstall and reinstall
- Check internet connection
- Verify API is accessible
- Check date/time is correct

### **PIN Not Working**
- Verify entered correctly (case-sensitive if set)
- Check caps lock off
- Try resetting PIN in Change PIN screen

### **Data Not Loading**
- Check internet connection
- Verify Railway API is online
- Try pull-to-refresh
- Restart app
