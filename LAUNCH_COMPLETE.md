## 📱 APK Build Instructions

### Option 1: Using EAS Cloud Build (Recommended)
```bash
cd finance-manager-mobile
npm install --legacy-peer-deps
npx eas login  # Sign up at expo.dev
npx eas build --platform android
```

### Option 2: Local Build (Troubleshoot Required)
The local Gradle build requires additional C++ build tools. Consider using EAS cloud build instead.

### Option 3: Pre-built APK
Contact Farooq for pre-built test APK or build in cloud using EAS.

2. **Open Claude Desktop** or Claude.ai
3. **Paste the prompt**
4. **Click "Generate image"**
5. **Download and use** for LinkedIn/marketing

**Recommended AI Image Tools:**
- Claude Desktop (built-in image generation)
